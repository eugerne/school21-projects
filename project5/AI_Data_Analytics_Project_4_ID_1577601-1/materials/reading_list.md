# Книги
* `Python for Data Analysis: Wes McKinney` — практическое руководство по работе с данными в Python. В этой книге нас особенно интересуют главы, посвященные визуализации данных, где показано, как с помощью matplotlib и встроенных возможностей pandas создавать наглядные графики и диаграммы для анализа и интерпретации данных.
* `«Что здесь изображено?» Дьяконов А. Г.` — практическое пособие-игра: участникам показывают графики (иногда с частично скрытыми элементами) и предлагают по ним угадать источник данных. Развивает навыки разведочного анализа, критическое мышление при интерпретации визуализаций, умение находить артефакты и формулировать гипотезы.
