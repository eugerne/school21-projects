## Глава I
### Преамбула
Визуализация данных — это один из важнейших инструментов аналитика, позволяющий преобразовать числовую и табличную информацию в наглядную графическую форму. Она помогает не просто «увидеть» данные, но и **понять** их: выявить закономерности, тренды, взаимосвязи и аномалии, которые могут быть неочевидны при работе с таблицами или агрегированными показателями. 

Сегодня от аналитика ждут не только умения работать с данными, но и способности донести выводы так, чтобы они были убедительны и наглядны. Для этого используются самые разные форматы — от простых графиков до интерактивных панелей и дашбордов. Визуализация становится связующим звеном между данными и решениями, помогая объяснять выводы, проверять гипотезы и формулировать рекомендации.

## Глава III
### Цели
В рамках данного проекта ты познакомишься с основными библиотеками для визуализации данных в Python:
* **Matplotlib** — базовый инструмент для построения графиков и тонкой настройки визуализаций.
* **Seaborn** — библиотека, построенная на основе Matplotlib, которая упрощает создание статистических графиков и визуализацию зависимостей между признаками.
* **Plotly** — современная библиотека для создания интерактивных визуализаций, подходящих для дашбордов и веб-приложений.

Работая с этими инструментами, ты научишься подбирать оптимальные способы представления данных под конкретные задачи анализа, создавать информативные и эстетичные визуализации, а также использовать графики как инструмент для выдвижения и проверки аналитических гипотез. В рамках проекта ты продолжишь работу с данными опроса Kaggle Machine Learning & Data Science Survey, применяя изученные методы для визуального исследования ответов и выявления интересных закономерностей в сообществе специалистов по данным.

### Бонусное задание. Dash

**Dash** — фреймворк на Python для создания веб-сервисов с интерактивными визуализациями. В этом задании ты создашь интерактивный дашборд для анализа данных.

#### Требования к данным

Используй любые данные по выбору. Примеры подходящих датасетов: результаты опросов, экономические показатели, данные о продажах, спортивная статистика, климатические данные и т. д. 

Данные должны содержать разнообразные типы признаков (категориальные, числовые, временные ряды, географическая информация) для создания различных типов визуализаций.

#### Требования к веб-сервису

1. **Структура и навигация:**
   - Сделай минимум 3 страницы с возможностью переключения между ними.
   - На страницах должен быть видимый элемент для перехода между ними.
   - Пусть первая страница содержит главную информацию и графики, дающие общее представление о данных.
   - Остальные страницы — это специализированные страницы для детального анализа различных аспектов данных.

2. **Интерактивность:**
   - Постарайся добавить больше интерактивности в свой дашборд. Добавь возможность интерактивной фильтрации различными способами.
   - Сделай минимум 2 фильтра, которые влияют на отображаемые графики.
   - Пусть графики автоматически обновляются при изменении фильтров.
   - Примеры форм фильтров: выпадающий список (dropdown), ползунок для выбора диапазона значений (range slider), чекбоксы для множественного выбора (checkboxes) и т. д.

3. **Визуализации:**
   - Дашборд нужно красиво оформить: графики должны быть информативными, понятными и визуально привлекательными.
   - Сделай минимум 4 различных типа графиков.
   - На каждом графике обязательно должны быть: информативный заголовок, подписи осей и легенда для объяснения элементов графика.

4. **Оформление проекта:**
   - Файл `README_dash.md` в папке `src/dash` должен содержать:
     - Описание проекта: краткое описание дашборда, какие данные используются, ссылки на источники данных (если данные взяты из открытых источников).
     - Инструкции по установке: как установить зависимости из файла `requirements.txt`.
     - Инструкции по запуску: команда для запуска веб-сервиса, на каком адресе и порту он будет доступен после запуска.
   - Файл `requirements.txt` в папке `src/dash` должен содержать все необходимые библиотеки и их версии для корректной работы дашборда.
